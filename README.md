# Burrow Lane website

Public site for the Burrow Lane games for children (Fire Station Crew, Baby Dragons, Ice Cream Parlour), served by GitHub Pages, like logic-mastermind-site.

- `/` landing page
- `/privacy/` privacy policy (linked from Google Play and from the games' parent corner), `/privacy/pl/` in Polish
- `/terms/` terms (purchases and the Burrow Lane Pass), `/terms/pl/`
- `/support/` help and contact, `/support/pl/`

Static HTML, no build step. Each page has /<lang>/ versions: pl, es, pt, it, fr (D-039).

Before publishing: confirm the support e-mail (placeholder `support@burrowlane.app`) and the publisher name.
