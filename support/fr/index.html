Où sont les réglages ?

Touchez la roue dentée sur le premier écran et répondez à la question pour les adultes. Le coin des parents contient le minuteur, la langue, les sous-titres, le son, la progression de votre enfant, les achats et « Supprimer les données de cet appareil ».

J’ai acheté, mais les épisodes sont toujours fermés

Dans le coin des parents, touchez « Restaurer les achats ». Vérifiez que l’appareil utilise le même compte Google que celui qui a fait l’achat. Pour le Pass Burrow Lane, ouvrez une fois le jeu dans lequel vous l’avez acheté, pour que les autres jeux de l’appareil le voient.

Comment résilier le Pass ?

Dans Google Play : votre photo de profil, Paiements et abonnements, Abonnements, Pass Burrow Lane, Résilier. Le bouton « Gérer l’abonnement » du coin des parents y mène directement.

Le minuteur a arrêté le jeu

C’est le minuteur que vous avez réglé. Quand le temps est écoulé, l’épisode en cours se termine et le jeu dit bonne nuit. Un adulte peut le réveiller, ou changer le minuteur dans le coin des parents. Le temps se compte par jour.

Faut-il une connexion internet ?

Non. Seuls l’achat et la restauration des achats communiquent avec Google Play.
